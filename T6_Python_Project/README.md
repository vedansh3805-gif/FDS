# T6 Python Project

## Objective
To create a Python project and demonstrate debugging and unit testing.

## Project Features
- Python project structure
- VS Code debugging
- Breakpoints
- Step Over, Step Into and Step Out
- PDB debugging
- Error identification using traceback
- Unit testing using unittest

## Files
- `main.py` - Main program
- `src/calculator.py` - Calculator functions
- `tests/test_calculator.py` - Unit tests
- `requirements.txt` - Project dependencies

## Run the Program

```bash
python3 main.py
